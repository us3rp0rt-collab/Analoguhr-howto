1

Das Zifferblatt: die Bühne der Uhr

Ein HTML-Element wird mit CSS zum Kreis.

Wir legen zuerst ein <div> an. Es ist der Behälter für alle späteren Teile. Gleiche Breite und Höhe sowie border-radius: 50% machen daraus einen Kreis. Die Umrandung zeigt, wo die Uhr endet.

Warum position: relative? So können Markierungen und Zeiger später mit position: absolute genau innerhalb dieses Kreises platziert werden.

Teste rechts: Blende das Zifferblatt aus. Ohne die Bühne ist schwer zu erkennen, wo die Uhr beginnt und endet.

Mini-Check: Was macht den Behälter rund?

🔬 Experiment: Bühne

Die blaue Umrandung und der helle Kreis sind CSS.

Der passende Code
<div class="clock"></div>

.clock {
  position: relative;      /* Bezugspunkt für alle Uhrenteile */
  width: 300px;
  height: 300px;           /* gleiche Höhe und Breite */
  border-radius: 50%;      /* aus dem Quadrat wird ein Kreis */
  border: 12px solid royalblue;
  background: white;
}
2

Stundenstriche und Zahlen: Orientierung

Zwölf gleichmäßige Plätze teilen den Vollkreis.

Ein ganzer Kreis hat 360°. Für zwölf Stundenmarkierungen rechnen wir 360° ÷ 12 = 30°. Eine Schleife erzeugt zwölf Striche; der erste steht oben, jeder nächste ist um 30° weitergedreht. Bei jedem fünften Minutenstrich entsteht ein kräftiger Stundenstrich.

Die Zahlen setzen wir mit Sinus und Kosinus auf einen gedachten Kreis um die Mitte. Für die 12 ziehen wir 90° ab, denn die Mathematik beginnt rechts bei 3 Uhr, unsere Uhr aber oben bei 12 Uhr.

Schalte Striche und Zahlen getrennt ein und aus. Welche Information ist auch ohne Zahlen noch gut erkennbar?

Mini-Check: Wie viel Grad liegen zwischen zwei Stunden?

🔬 Experiment: Orientierung

Der passende Code
// 60 kleine Striche: 360° / 60 = 6° Abstand.
for (let minute = 0; minute < 60; minute++) {
  const strich = document.createElement("span");
  strich.className = minute % 5 === 0 ? "tick major" : "tick";
  strich.style.transform = `rotate(${minute * 6}deg)`;
  zifferblatt.append(strich);
}

// Die Zahlen liegen auf einem gedachten Kreis um (50 %, 50 %).
for (let stunde = 1; stunde <= 12; stunde++) {
  const winkel = (stunde * 30 - 90) * Math.PI / 180;
  zahl.style.left = `${50 + 38 * Math.cos(winkel)}%`;
  zahl.style.top  = `${50 + 38 * Math.sin(winkel)}%`;
}
💡 Warum Bogenmaß? JavaScripts Math.sin() und Math.cos() erwarten Bogenmaß. Darum wandeln wir Grad mit Math.PI / 180 um.
3

Der Mittelpunkt: hier drehen sich die Zeiger

Ein kleiner Punkt verdeckt die Zeigeransätze.

Die Zeiger treffen sich genau bei left: 50% und top: 50%. Der Mittelpunkt markiert diesen gemeinsamen Drehpunkt. translate(-50%, -50%) verschiebt den Punkt um seine halbe Größe zurück: So liegt seine eigene Mitte exakt in der Uhrenmitte.

Mini-Check: Warum verschieben wir den Punkt um −50 %?

🔬 Experiment: Drehpunkt

Der passende Code
<span class="center-dot"></span>

.center-dot {
  position: absolute;
  left: 50%; top: 50%;  /* Ziel: Mitte des Zifferblatts */
  transform: translate(-50%, -50%);
  border-radius: 50%;
  z-index: 5;            /* liegt sichtbar über den Zeigern */
}
4

Drei Zeiger, drei Aufgaben

Stunde, Minute und Sekunde unterscheiden sich durch Länge und Farbe.

Jeder Zeiger ist ein schmales Rechteck. Sein unteres Ende sitzt in der Mitte der Uhr. Mit transform-origin: 50% 100% dreht er sich um genau dieses Ende. Der Stundenzeiger ist kurz und dunkel, der Minutenzeiger länger und blau, der Sekundenzeiger dünn und rosa.

Bewege den Regler. Alle drei zeigen hier absichtlich denselben Testwinkel, damit du ihre Längen vergleichen kannst. Danach kannst du jeden einzeln ausblenden.

Mini-Check: Wo muss der Drehpunkt eines Zeigers liegen?

5

Aus Uhrzeit werden Winkel

Jetzt bekommt jeder Zeiger seinen eigenen Platz.

Sekunden: Eine volle Runde in 60 Sekunden, also 6° × Sekunden. Minuten: Ebenfalls 6° pro Minute. Die Sekunden geben einen kleinen Zusatz, damit sich der Minutenzeiger gleichmäßig bewegt.

Stunden: Eine volle Runde in 12 Stunden, also 30° × (Stunden mod 12). Pro Minute wandert er weitere 0,5°. Ohne diesen Zusatz würde er erst zur nächsten vollen Stunde springen.

Wähle eine Uhrzeit. Vergleiche zum Beispiel 03:00 mit 03:30: Der Stundenzeiger steht um halb vier bereits zwischen 3 und 4.

Mini-Check: Wo steht der Stundenzeiger um 03:30?

🔬 Experiment: Uhrzeit berechnen

Der passende Code
function berechneWinkel(stunden, minuten, sekunden) {
  return {
    // 30° pro Stunde + 0,5° pro Minute + kleiner Sekundenanteil
    stunde: (stunden % 12) * 30 + minuten * 0.5 + sekunden / 120,
    // 6° pro Minute + 0,1° pro Sekunde
    minute: minuten * 6 + sekunden * 0.1,
    // 6° pro Sekunde
    sekunde: sekunden * 6
  };
}

function setzeZeiger(uhr, winkel) {
  for (const [name, grad] of Object.entries(winkel)) {
    uhr.querySelector(`.hand.${name}`)
      .style.setProperty("--angle", `${grad}deg`);
  }
}
💡 Warum zwei Funktionen? berechneWinkel übersetzt Zahlen in Grad. setzeZeiger zeigt diese Gradwerte an. So kannst du die Rechnung unabhängig von der Darstellung testen.
6

Die Animation: immer die aktuelle Zeit

JavaScript fragt die Systemzeit ab und aktualisiert die Zeiger.

new Date() liest die aktuelle Uhrzeit deines Geräts. Die Funktion zeichneAktuelleZeit() holt Stunden, Minuten und Sekunden, berechnet die Winkel und bewegt die Zeiger. setInterval(..., 50) ruft sie regelmäßig auf. Wir starten sie auch sofort einmal, damit die Uhr nicht erst nach dem ersten Intervall erscheint.

Der Sekundenzeiger kann dank Millisekunden in kleinen Schritten weiterlaufen. Die angezeigte Zeit stammt immer frisch aus dem System und driftet deshalb bei einer verzögerten Browser-Aktualisierung nicht dauerhaft weg.

Mini-Check: Warum lesen wir die Systemzeit bei jedem Durchlauf neu?

🔬 Experiment: Start und Pause

Die Vorschau wartet auf deinen Start.

Der passende Code
function zeichneAktuelleZeit(uhr) {
  const jetzt = new Date();       // aktuelle Zeit des Geräts
  const sekunden = jetzt.getSeconds() + jetzt.getMilliseconds() / 1000;
  const winkel = berechneWinkel(
    jetzt.getHours(), jetzt.getMinutes(), sekunden
  );
  setzeZeiger(uhr, winkel);
}

zeichneAktuelleZeit(uhr);                  // sofort zeichnen
const timer = setInterval(() => {
  zeichneAktuelleZeit(uhr);                // regelmäßig erneuern
}, 50);

// Bei Bedarf anhalten: clearInterval(timer);
